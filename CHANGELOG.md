# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-14

### Added
- **Native Android UI**: Built from the ground up with Jetpack Compose, Material 3, and Material You dynamic theming.
- **Media Browsing**: Full pagination, searching, and sorting for Scenes, Performers, Studios, and Tags.
- **Video Player**: ExoPlayer-based playback with custom scrubber, aspect ratio adjustment, and resume tracking.
- **StashDB Integration**: Direct querying and metadata scraping for performers, studios, and scenes.
- **Whisparr Integration**: Download queue monitoring, release search, and status tags.
- **Offline Cache**: Room SQLite database with async prefetching and offline state preservation.
- **Fluid Animations**: Shared element transitions between list and detail views.
